ADR：QyTable renderer 职责基线 ​

日期：2026-08-29 状态：Accepted

背景 ​

QyTable 当前在满足 virtual 准入条件时使用 VxeVirtualTableRenderer，否则使用 ElementTableRenderer。两者都是内部 adapter；业务侧只依赖 Qy props、events、slots 和 QyTableExpose。这份 ADR 固化后续收敛职责时的判断基线，而非宣称任一 renderer 已经可以无差别替换。

审计以当前源码、@qynpm/table-schema 和本地安装的 vxe-table@4.21.0 的公开类型、 配置、事件及实例方法为依据。$el、厂商 store/reactData、列对象字段和依赖 CSS class 查询到的 DOM 都不是可新增的长期依赖；本 ADR 中提到它们时，仅是在记录当前实现需要 后续以公开 API 或 Qy 语义证明后才能保留的事实。

决策 ​

  1. VXE 负责虚拟 DOM、实际滚动与尺寸计算、fixed 列，以及它已公开提供的基础表格 交互。未来能力默认首先以 VXE-native adapter 评估，而不是在 Qy 层重造表格引擎。
  2. Qy 负责公开 interface、受控状态与事件顺序、完整树先序的 canonical rowIndex、 业务 schema，以及 VXE 无法表达或与 Qy 契约不一致的语义。
  3. ElementTableRenderer 和 table-schema 都只是内部 adapter。前者不定义公共行为， 后者负责列 schema、展示/编辑/action 映射，不能取得 renderer 的状态所有权。
  4. 新增或收敛能力只能使用 VXE 的公开 props/config、公开事件和公开实例方法；不把 DOM、store、reactive internal state 或 VXE column object 暴露给业务，也不以它们作为 新架构方案。
  5. 下表的 Evidence Required 表示当前源码或 VXE 类型不足以证明可替换；在原生对照 测试、Qy 契约测试和需要时的真实 DOM 证据齐备前，保持现有 Qy-owned 语义。

现状与职责矩阵 ​

标记含义：VXE Native 为可由 VXE 4.21 公共能力承载；Qy Adapter 为内部映射； Qy Owned 为不能交给厂商的稳定语义；Evidence Required 为替换或扩大支持前必须 补齐的证据。一个能力可同时有多个标记。

VXE 组合限制 ​

以下不是产品禁令，而是默认的实现门槛：在对应原生组合测试和 Qy 契约测试通过前， 不开放或不替换现有行为。

  • tree checkbox range：平铺数据可评估 isShiftKey 与 range 事件；树投影不把原生 range 当作 Qy 的完整树先序语义。
  • spanMethod 当前强制 Element fallback；通用动态行高与 virtual 仍不组合。详情 expand 使用固定基础行高和内部限高滚动，行窗口、锚点和详情高度继续以真实 DOM 证明。
  • tree、懒加载、排序筛选：原生树状态不能替代 Qy 的递归筛选、稳定排序和受控 key 事件顺序。
  • 列拖拽与 fixed/column settings：提交后的 Qy columnSettings 才是唯一持久状态；只保证 当前已挂载横向列窗口内拖拽，跨窗口自动滚动落点保持 Unsupported/Deferred。

后续收敛方向 ​

低风险：继续收敛公开滚动与 layout ​

  • 范围：维持 QyTableExpose 的 Qy-owned 滚动方法和基于 VXE scrollTo、recalculate、 refreshScroll 的 resize/layout；继续用公开 render width 替换仅存于详情高度测量的 DOM 证据。
  • 验收：Qy key/offset 恢复测试、真实 resize/fixed DOM 路径和详情高度的独立证据。
  • 不做：不暴露 VXE instance、column object、$el 或 CSS class。

中风险：收敛平铺 selection/current/expand ​

  • 范围：先建立 VXE native 与 Qy 并排测试，覆盖 reserve、selectable、Shift、current、 tree/详情 expand 的 controlled/uncontrolled 事件顺序；仅对已等价的平铺路径移除重复同步。
  • 验收：每一项同时证明原生事件 payload、Qy emits、受控父级拒绝恢复和 canonical rowIndex。
  • 不做：不把树 range 或详情/树共 key 的投影委托给 VXE。

高风险：仅在原生完整满足 Qy 契约时替换 ​

  • 范围：树投影、排序筛选和编辑/浮层生命周期分别做原生能力 spike；只有原生实现能 完整满足 Qy 的投影、事件顺序、编辑取消、权限和窗口卸载语义时才替换局部实现。
  • 验收：完整 Qy contract matrix、真实虚拟 DOM/teleport 证据、组合限制矩阵；任一缺口 保持 Qy-owned。
  • 不做：不以绿色 build、内部 store 或单个 VXE demo 作为替换依据。

审计证据 ​

  • Qy facade 与公共类型：packages/table/src/table/QyTable.vue、types.ts。
  • 现有两个内部 adapter：ElementTableRenderer.vue、VxeVirtualTableRenderer.vue；后者 当前使用 scroll-y、virtual-x-config、checkbox-config、expand-config、公开事件 和公开实例方法，同时包含本 ADR 明确不应扩散的 $el/DOM 读取。
  • schema 与 renderer-neutral column 映射：packages/table/src/table/adapters/table-schema.ts 及 packages/table-schema/src。
  • 现有行为证据：packages/table/__tests__/QyTable.spec.ts、 ElementTableRenderer.spec.ts、VxeVirtualEditCell.spec.ts、table-schema 测试。
  • VXE 公开面：本地 node_modules/.pnpm/vxe-table@4.21.0/node_modules/vxe-table 的 types/index.d.ts、types/all.d.ts 与 table 实现导出的配置/事件/实例方法；版本同时由 packages/table/package.json 的 devDependency 固定。
