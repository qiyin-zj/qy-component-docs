@qynpm/utils ​

起印公共浏览器工具包，提供历史兼容的日期/金额格式化、输入清洗、类型判断、复制、gzip 文本编码、拼音首字母、图片压缩和系统基础地址构造。它不依赖 Vue 或 Element Plus，也不读取业务环境变量、store 或路由。

这些 API 中有一部分刻意保留旧行为，函数名不一定等于常见直觉；迁移前应阅读下方精确语义。

安装与本地联调 ​

源码中的版本号不等于该版本已经发布。先从 npm registry 或消费者 lockfile 确认目标版本确实可用，再安装：

bash
pnpm add @qynpm/utils

包同时提供兼容根入口以及按依赖隔离的子路径；每个入口都有 ESM、CommonJS 和类型声明。根入口仍会聚合加载全部工具；只需要单类能力时应使用下表子路径，避免加载无关第三方依赖。

入口能力第三方运行时依赖
@qynpm/utils/core复制、判断、系统基础地址无
@qynpm/utils/encodinggzip Base64pako
@qynpm/utils/date日期/时间格式dayjs
@qynpm/utils/number金额和输入清洗number-format.js
@qynpm/utils/pinyin拼音首字母pinyin-pro
@qynpm/utils/image图片压缩无

本地联调由消费者显式 alias 到源码入口或已存在的构建产物；alias 不代表 npm 已发布，也不要重建正在被其他项目使用的 dist。

推荐的新代码按能力导入；根入口只用于兼容已有调用：

ts
import { buildSystemBaseUrl, isEmpty } from '@qynpm/utils/core'
import { YYYYMMDD } from '@qynpm/utils/date'
import { pakoEncode, pakoParse } from '@qynpm/utils/encoding'
import { amountFormatter } from '@qynpm/utils/number'

console.log(YYYYMMDD(new Date()))
console.log(amountFormatter(1234.5))
console.log(isEmpty([]))

const encoded = pakoEncode('中文😀')
console.log(pakoParse(encoded))

const baseUrl = buildSystemBaseUrl('erp', { origin: location.origin })

拼音首字母 ​

ts
import { getFirstLetter } from '@qynpm/utils/pinyin'

getFirstLetter('中文 A') // 'ZW A'
getFirstLetter('hello')  // 'HELLO'
getFirstLetter('')       // ''

getFirstLetter(text: string): string 使用 pinyin-pro 的 type: 'array'、toneType: 'none' 分词，并把每个 token 的首字符转成大写。它保留中文、ASCII、空格和混合文本的旧分词结果。与旧复制版本不同，公开参数只接受字符串，空字符串稳定返回 ''；不再发布 any 入参，也不保留 null/undefined 的抛错或 undefined 返回差异。

图片压缩 ​

ts
import { compressImage } from '@qynpm/utils/image'

const controller = new AbortController()
const compressed = await compressImage(
  file,
  { maxWidth: 1920, maxHeight: 1080, signal: controller.signal },
  500
)

compressImage(file: Blob, options?: CompressImageOptions, sizeImage = 500): Promise<Blob> 的第三个参数单位为 KiB。CompressImageOptions 只包含：

  • maxWidth?: number、maxHeight?: number：按比例缩小，不放大；同时提供时取更严格的比例。
  • signal?: AbortSignal：解码前、解码中或编码中取消时以名称为 AbortError 的异常拒绝。

实现使用浏览器原生 Image、object URL 和 Canvas，因此调用环境必须提供 DOM、Canvas 2D 与 HTMLCanvasElement.toBlob。输出沿用输入 MIME；输入未声明 MIME 时使用 image/jpeg。编码会尝试有限个质量档位：达到目标即返回；若目标因格式或内容不可达，则返回本轮最小的有效 Blob，不会无限递归或保持 pending。图片解码失败、Canvas 2D context 不可用或编码返回空 Blob 时 Promise 会拒绝；所有终态都会撤销 object URL 并移除事件处理器。

迁移差异：保留旧 maxWidth、maxHeight 选项和第三个位置参数，但不再透传 compressorjs 私有选项；错误不再只写 console.error，而会拒绝 Promise；不可达目标改为有限 best-effort 结果；新增取消能力，且不依赖 compressorjs。

日期与表格时间 ​

API返回格式兼容语义
YYYYMMDD(value)YYYY-MM-DD HH:mm:ss名称虽然像纯日期，实际包含日期和时间。
YYYYMM(value)YYYY-MM-DD名称虽然像年月，实际包含年月日。
MMDD(value)HH:mm:ss名称虽然像月日，实际只返回时分秒。
timeFormat(row, column, value, index)YYYY-MM-DD HH:mm:ss表格 formatter 兼容签名，只格式化第三个参数。

上述日期 API 对 0、false、空字符串、null、undefined、NaN 等 falsey 值返回空字符串，因此 Unix epoch 的数字 0 不会格式化。其他值交给 dayjs 解析。

ts
YYYYMMDD(new Date(2024, 0, 2, 3, 4, 5)) // 2024-01-02 03:04:05
YYYYMM(new Date(2024, 0, 2, 3, 4, 5))   // 2024-01-02
MMDD(new Date(2024, 0, 2, 3, 4, 5))     // 03:04:05
YYYYMMDD(0)                              // ''

金额和输入清洗 ​

API返回值与行为
amountFormatter(value)两位小数和千分位，如 1234.5 -> '1,234.50'。
amountFormat(row, column, value, index?)表格 formatter 兼容签名，只把第三个参数交给 amountFormatter。
amountFormatRatio(value, index?)同样委托给 amountFormatter；不会乘以 100，也不会添加 %。
thousandDivider(value)按整数千分位规则四舍五入；空值和 0 返回数值 0，其他情况返回字符串。
inputAmountFormatter(mask?)返回字符串清洗函数；删除数字和点之外的字符，并把多个点合并到一个小数点后。

inputAmountFormatter 的 mask 参数目前只为兼容旧调用保留，不参与格式化。它不是金额校验器：会移除负号和字母，允许 .5，不限制小数位，也不判断上下限。

ts
amountFormatter(-1234.5)                  // '-1,234.50'
amountFormat({}, {}, 1234.5)              // '1,234.50'
amountFormatRatio(0.25)                    // '0.25'，不是 '25%'
thousandDivider(0)                         // 0
thousandDivider(1234.5)                    // '1,235'
inputAmountFormatter('ignored')('-1,2.3x') // '12.3'

类型判断 ​

  • isEmpty(value)：false、空字符串、null、undefined、NaN、空数组和无自有可枚举 key 的普通对象为 true；数字 0、true、'0'、Infinity、非空数组和带 key 的对象为 false。
  • isFunction(value)：仅判断 typeof value === 'function'，普通函数、异步函数和 class 都会通过。
  • isNumber(value)：仅接受 primitive number 且排除 NaN；Infinity、-Infinity 仍为 true，数字字符串和 new Number() 为 false。
ts
isEmpty(0)                  // false
isEmpty(Number.NaN)         // true
isEmpty({ key: undefined }) // false
isNumber(Infinity)          // true
isNumber('1')               // false

复制 ​

copy(text, useNavigator = false): Promise<void> 接受字符串或数字。默认创建临时 textarea 并调用 document.execCommand('copy')；传 true 时改用 navigator.clipboard.writeText()。两种路径最终都会清理 textarea。

ts
await copy('订单号')
await copy(12345, true)

浏览器复制异常会在函数内部捕获并通过 console.error('复制失败', error) 记录，Promise 仍会 resolve。因此 await copy() 成功结束只表示流程完成，不能证明内容已经写入剪贴板。Clipboard API 还受安全上下文和浏览器权限限制；需要明确成功反馈时，宿主应采用能验证结果的交互方案。

gzip Base64 文本 ​

  • pakoEncode(text): string：把 UTF-8 字符串 gzip 后编码为带合法 padding 的标准 Base64。
  • pakoParse(encoded): string：接受标准 Base64，也接受 Base64URL 字符和缺失 padding；解压并按 UTF-8 返回字符串。
ts
const encoded = pakoEncode(JSON.stringify({ name: '样品' }))
const text = pakoParse(encoded)
const value = JSON.parse(text)

pakoParse 返回字符串，不会自动 JSON.parse。非法 Base64、错误 padding 或非 gzip 内容会抛出异常，调用方自行处理。

系统基础地址 ​

ts
import { buildSystemBaseUrl } from '@qynpm/utils'

const currentOriginBase = buildSystemBaseUrl('erp', {
  origin: location.href
})

const mappedBase = buildSystemBaseUrl('erp', {
  origin: location.href,
  baseUrls: {
    erp: new URL('/gateway/erp', location.origin)
  }
})

const pageUrl = `${mappedBase}orders?code=${encodeURIComponent('A/B')}`

BuildSystemBaseUrlOptions：

字段类型说明
originstring | URL必填。没有映射时只取它的 origin，并生成 /<system>/。原有 path、query、hash 不保留。
baseUrlsReadonly<Record<string, string | URL | undefined>>可选。按完整 system key 提供绝对映射地址。

精确规则：

  • system 必须是非空单一路径段；空白、/、?、# 会抛出 TypeError。
  • 没有对应映射或值为 undefined 时，结果为 new URL(origin).origin + '/<system>/'。
  • 映射必须是干净的绝对 URL，不能含用户名、密码、query 或 hash；相对地址和无 hostname 地址会抛出 TypeError。
  • 映射的既有 pathname 会保留，并规范为一个结尾 /；默认端口按 URL 标准归一化。
  • 工具只生成 base URL，不拼业务 route、query，也不判断开发/生产环境。
  • origin、映射表和环境选择都由宿主配置；不要把内部域名、令牌或部署拓扑写进公共包。

全部公开导出 ​

根入口公开 18 个运行时 API：

  • 复制：copy
  • 编码：pakoEncode、pakoParse
  • 日期：YYYYMMDD、YYYYMM、MMDD、timeFormat
  • 金额：amountFormatter、amountFormat、amountFormatRatio、thousandDivider、inputAmountFormatter
  • 判断：isEmpty、isFunction、isNumber
  • 地址：buildSystemBaseUrl
  • 拼音：getFirstLetter
  • 图片：compressImage

另公开类型 BuildSystemBaseUrlOptions、CompressImageOptions。

运行环境与迁移边界 ​

  • 包面向现代浏览器/Web API 运行时。根模块可以在没有 DOM 的环境中导入，但调用 copy 或 compressImage 需要 DOM；复制的 navigator 路径还需要 Clipboard API。
  • gzip API 依赖 TextEncoder、TextDecoder、btoa 和 atob。
  • 历史命名和 falsey 行为为兼容契约；迁移时不要根据函数名擅自修正格式。
  • 本包不提供金额合法性校验、百分比换算、JSON 编解码、业务配置、小程序兼容层或环境探测。
