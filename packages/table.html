@qynpm/table@1.0.1@qynpm/tableoverview

QyTable 表格

面向后台列表的统一表格门面。普通数据由 Element renderer 承载，大数据在满足准入条件时切换到 VXE 4.21 虚拟 renderer；业务代码始终使用同一套 Qy 列模型、事件上下文和公开方法。

  • 普通 / 虚拟统一 API
  • 递归树与分组列
  • 受控选择与当前行
  • 六类编辑列
快速开始普通表格功能示例虚拟表格功能指南Renderer 矩阵完整 API性能与边界

快速开始

安装包及宿主依赖后，只需要传入原始行数据与 Qy-owned 列 schema。页面不直接创建 Element 或 VXE column。

Terminal
pnpm add @qynpm/table
Vue · TypeScript
<script setup lang="ts">
import { QyTable, type QyTableColumn } from '@qynpm/table'

type OrderRow = {
  id: string
  code: string
  name: string
  status: string
}

const rows: OrderRow[] = [
  { id: '1', code: 'QY-1001', name: '包装盒彩样', status: 'done' },
  { id: '2', code: 'QY-1002', name: '标签打样', status: 'processing' }
]

const columns: QyTableColumn<OrderRow>[] = [
  {
    key: 'selection',
    label: '选择',
    type: 'selection',
    width: 52
  },
  {
    key: 'code',
    label: '编号',
    prop: 'code',
    width: 130,
    copy: true
  },
  { key: 'name', label: '名称', prop: 'name', minWidth: 180 },
  { key: 'status', label: '状态', prop: 'status', type: 'tag' }
]
</script>

<template>
  <QyTable
    :data="rows"
    :columns="columns"
    row-key="id"
  />
</template>
身份字段很重要：普通平铺表可使用默认 id；selection、树形、受控 current/expand 和虚拟表格应显式提供稳定、唯一的字符串字段 rowKey。

虚拟表格

VXE virtual renderer

设置 virtual 后，完整树节点数必须大于 virtualMinRows 才会激活。 基础行高由 virtualRowHeight 固定；超过 virtualMinColumns 的平铺叶子列会进一步启用横向虚拟。

<QyTable
  :data="rows"
  :columns="columns"
  row-key="id"
  virtual
  :virtual-min-rows="100"
  :virtual-min-columns="24"
  :virtual-row-height="36"
  height="520"
/>
不要把 virtual 当成强制 renderer：重复 rowKey、多个 selection 列、spanMethod、legacy setup 等组合会回退 Element。开发环境会输出明确原因。

功能指南

DATA & COLUMNS

列模型与展示

一个 schema 同时适配普通与虚拟 renderer。
  • 嵌套 prop、formatter、render 与 cell/header/footer slot
  • 递归 children 分组、fixed、列显隐/宽度/顺序设置
  • enum、tag、status、copy、profile、image 与 actions

INTERACTION

选择与当前行

公开状态由 Qy 契约控制。
  • selectedRowKeys、selection-change 与四个 selection expose
  • selectable、reserveSelection 与平铺 Shift 区间
  • currentRowKey、current-change 与受控拒绝恢复

QUERY

排序与筛选

本地和 custom/event 模式可以按列组合。
  • sortable、sortMethod、sortBy、sortOrders
  • filters、filterMethod、filteredValue、同列 OR/多列 AND
  • 虚拟树按层稳定排序，深层筛选保留祖先路径

TREE & DETAILS

树、懒加载与详情

canonical rowIndex 始终按完整树先序。
  • childrenKey、受控 expandedRowKeys 与 expand 详情
  • hasChildrenKey + loadChildren single-flight/Abort
  • 选择、current 与展开状态在折叠/过滤隐藏时保留

EDITING

六类编辑列

编辑直接写回原 row，并在值变化时发一次事件。
  • input、select、date、checkbox、switch、autocomplete
  • controlProps 与同步/异步 options
  • 虚拟回收、查询重排、renderer 切换的提交/取消边界

LAYOUT

汇总、合并与样式

优先适配厂商公开布局能力。
  • 单行 summary Footer 与 footer slot
  • spanMethod 数据区合并会回退 Element
  • renderer-neutral row/cell/header class 与 style 上下文

列类型

type用途Virtual关键配置
default普通数据、slot、formatter/render支持prop、copy、sortable、filters
index序号列支持width、fixed
selection复选列（最多一列）支持selectable、reserveSelection

Renderer 选择与 fallback

组件自动选择内部 renderer，页面不应依赖内部实例。下面的条件按当前源码与 VXE 4.21 组合边界整理。

场景实际 renderer行为
virtual=false，或数据量未超过阈值Element普通表格；允许浏览器原生可变行高。
virtual=true，行数超过阈值，rowKey 与列能力合法VXE 4.21启用纵向虚拟；列数超过阈值时平铺表启用横向虚拟。
存在递归分组表头VXE 4.21保留纵向虚拟，关闭横向虚拟；所有可见叶子列会挂载。
传入 spanMethodElement数据区合并；移除后重新按 virtual 条件选择 renderer。
重复/缺失 rowKey、多个 selection、unsupported columnElement fallback开发环境警告；公共状态与事件接口不改变。
通用动态行高、区域复制、跨虚拟窗口列拖拽Deferred当前不宣称支持，不自研第二套布局/区域引擎。
